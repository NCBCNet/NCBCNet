# OKR评卷系统使用说明

## 功能概述

OKR评卷系统是一个完整的在线考试和评卷解决方案，支持**在线答题**和**扫描试卷**两种模式，主要包含以下功能：

### 1. 试卷分割功能
- 支持将试卷分成多个章节（Section）
- 每个章节可以包含多个不同类型的题目
- 章节可以按顺序组织，便于试卷结构化管理
- **支持定义图片分割区域**，用于扫描试卷自动分割

### 2. 在线评卷功能
- **在线答题模式**：学生在线答题和提交
- **扫描试卷模式**：上传纸质试卷扫描图片（类似高考）
- 选择题和多选题自动评分
- 主观题人工评卷
- 教师可以为每道题添加评语
- 实时查看评卷进度
- **按分节分配评卷教师**，支持多人协作评卷

### 3. 扫描试卷功能 🆕
- 📄 上传完整的试卷扫描图片
- ✂️ 自动按分节分割答题区域
- 👥 不同分节可分配给不同老师评卷
- 🖼️ 老师查看答题图片进行评分

> 详细使用说明请参考：[扫描试卷功能使用指南](../SCANNED_PAPER_GUIDE.md)

## 系统特性

### 考试模式
1. **在线答题** - 传统的网页表单答题
2. **扫描试卷** - 上传纸质试卷扫描图片

### 题型支持
1. **选择题（单选）** - 自动评分
2. **多选题** - 自动评分
3. **问答题** - 人工评卷
4. **填空题** - 人工评卷

### 角色权限
- **学生**: 查看试卷、在线答题或上传扫描试卷、查看成绩
- **教师**: 创建试卷、分配评卷分节、评卷、查看所有提交

## 使用流程

### 教师端

#### 1. 创建试卷
通过Django后台管理界面（/admin/）创建试卷：

1. 登录管理后台
2. 进入"OKR评卷系统" → "试卷"
3. 点击"添加试卷"，填写：
   - 试卷标题
   - 试卷描述
   - 总分
   - 考试时长（分钟）
   - 是否启用

#### 2. 添加试卷分节
试卷创建后，添加分节：

1. 在试卷编辑页面，点击"添加试卷分节"
2. 填写分节标题和说明
3. 设置排序顺序
4. 保存

#### 3. 添加题目
在每个分节中添加题目：

1. 进入"题目"管理
2. 选择所属分节
3. 选择题目类型
4. 输入题目内容
5. 设置分值
6. 如果是选择题，添加选项并标记正确答案

#### 4. 评卷管理
1. 访问 `/okr_exam/grading/`
2. 可以按试卷和评分状态筛选
3. 点击"评卷"按钮进入评卷界面
4. 对于主观题，输入得分和评语
5. 点击"保存评分"完成评卷

### 学生端

#### 1. 查看试卷列表
- 访问 `/okr_exam/` 查看所有可用试卷

#### 2. 开始考试
1. 点击"开始考试"按钮
2. 系统自动创建提交记录
3. 进入答题界面

#### 3. 在线答题
- 对于选择题：选择一个选项
- 对于多选题：选择多个选项
- 对于主观题：在文本框中输入答案
- 可以随时点击"保存答案"保存进度
- 点击"提交试卷"完成考试

#### 4. 查看成绩
1. 访问 `/okr_exam/my-submissions/` 查看提交记录
2. 点击"查看详情"查看具体得分和评语

## 数据模型

### ExamPaper（试卷）
- 试卷标题、描述
- 创建者、创建时间
- 总分、考试时长
- 是否启用

### PaperSection（试卷分节）
- 所属试卷
- 分节标题、说明
- 排序顺序

### Question（题目）
- 所属分节
- 题目类型（选择题、多选题、问答题、填空题）
- 题目内容
- 分值

### QuestionOption（题目选项）
- 所属题目
- 选项内容
- 是否正确答案

### ExamSubmission（考试提交）
- 试卷和学生
- 开始时间、提交时间
- 总分、得分
- 是否已评分
- 评卷人、评卷时间

### Answer（答案）
- 提交记录和题目
- 答案内容
- 选中的选项
- 得分、评语

## URL路由

| URL | 功能 | 权限 |
|-----|------|------|
| `/okr_exam/` | 试卷列表 | 所有用户 |
| `/okr_exam/exam/<id>/` | 试卷详情 | 所有用户 |
| `/okr_exam/exam/<id>/start/` | 开始考试 | 登录用户 |
| `/okr_exam/take/<id>/` | 答题界面 | 登录用户 |
| `/okr_exam/submission/<id>/` | 提交详情 | 学生本人/教师 |
| `/okr_exam/my-submissions/` | 我的提交 | 登录用户 |
| `/okr_exam/grading/` | 评卷列表 | 教师 |
| `/okr_exam/grading/<id>/` | 评卷界面 | 教师 |

## 安装和配置

### 1. 安装依赖
系统基于Django 5.1.1，确保已安装所有依赖：

```bash
pip install -r requirements.txt
```

### 2. 创建数据库迁移
```bash
python manage.py makemigrations okr_exam
python manage.py migrate
```

### 3. 创建超级用户
```bash
python manage.py createsuperuser
```

### 4. 运行开发服务器
```bash
python manage.py runserver
```

### 5. 访问系统
- 后台管理: http://localhost:8000/admin/
- 试卷列表: http://localhost:8000/okr_exam/

## 技术特点

1. **分节设计**: 通过PaperSection模型实现试卷的分割功能，支持灵活的试卷结构
2. **自动评分**: 选择题和多选题自动评分，减轻教师负担
3. **在线评卷**: 教师可以在线评阅主观题，添加评语
4. **答题保存**: 学生可以随时保存答案，避免数据丢失
5. **权限控制**: 基于Django用户系统的权限管理
6. **响应式设计**: 使用Bootstrap构建的响应式界面

## 注意事项

1. 试卷一旦有学生提交，不建议修改题目和分值
2. 选择题的正确答案必须明确标记
3. 多选题需要选中所有正确答案才能得分
4. 考试时长仅供参考，系统不会强制限制答题时间
5. 建议定期备份数据库
