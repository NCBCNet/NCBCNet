# 文件上传进度条功能说明

## 新功能特性

### 1. Bootstrap 进度条模态框
- 使用Bootstrap 5模态框组件
- 美观的进度条动画效果
- 实时显示上传进度百分比

### 2. 用户相关信息显示
- 显示当前登录用户名
- 显示上传的文件名
- 显示文件大小（自动格式化为KB、MB、GB等）

### 3. 实时进度追踪
- 使用XMLHttpRequest的upload.progress事件
- 实时计算上传速度（B/s, KB/s, MB/s等）
- 实时计算剩余上传时间
- 进度条根据百分比动态改变颜色：
  - 0-50%: 蓝色 (info)
  - 50-99%: 黄色 (warning)  
  - 100%: 绿色 (success)

### 4. 上传控制功能
- **取消上传**：用户可以中途取消上传
- **错误处理**：网络错误、服务器错误等情况的友好提示
- **成功提示**：上传成功后自动刷新页面（3秒延迟）

### 5. AJAX异步上传
- 不会刷新整个页面
- 支持大文件上传
- 与nginx配置配合，支持2GB以内的文件

### 6. 用户体验优化
- 模态框背景禁止点击关闭（防止误操作）
- 上传过程中禁用ESC键关闭
- 明确的状态提示和按钮控制

## 技术实现

### 前端技术
- Bootstrap 5 模态框和进度条组件
- XMLHttpRequest Level 2 上传进度API
- JavaScript事件处理和DOM操作
- 文件大小和时间格式化函数

### 后端支持
- Django视图处理文件上传
- 用户身份验证和授权
- 文件保存到指定文件夹

### Nginx配置
- 支持2GB大文件上传 (client_max_body_size 2G)
- 流式上传优化 (proxy_request_buffering off)
- 超时时间设置 (300秒)

## 使用说明

1. 用户登录后进入云上网盘
2. 选择要上传的文件
3. 点击"上传文件"按钮
4. 自动弹出进度条模态框，显示：
   - 用户名
   - 文件名
   - 文件大小
   - 上传百分比
   - 上传速度
   - 剩余时间
5. 等待上传完成或点击"取消上传"
6. 上传成功后自动刷新页面显示新文件
